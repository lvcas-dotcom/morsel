# Morsel — Brand

## Símbolo
Um "m" minúsculo construído com traços contínuos de pontas arredondadas, com uma **mordida** limpa no canto superior direito: um único arco côncavo, centrado na diagonal de 45° do canto, para manter a simetria.

- O "m" representa a marca.
- A mordida representa o produto: o agente pega só o pedaço de que precisa.

## Arquivos

| Arquivo | Uso |

| `morsel-icon.svg` | Ícone de app/org (fundo escuro, cantos arredondados) |
| `morsel-social.svg` | Social preview do GitHub (1280×640) |

Todos os textos estão convertidos em curvas, então os arquivos não dependem de fontes instaladas.

## Cores

| Nome | Hex | Papel |
|---|---|---|
| Amber | `#FFB547` | Início do gradiente, destaque |
| Coral | `#FF5A36` | Cor principal da marca |
| Ember | `#E8361C` | Fim do gradiente |
| Ink | `#17120F` | Texto sobre claro |
| Night | `#120E0B` | Fundo escuro |
| Cream | `#FFF6EE` | Texto sobre escuro, fundo claro |

Gradiente do símbolo: linear em diagonal (do topo-esquerda para baixo-direita), Amber 0% → Coral 55% → Ember 100%, com grão sutil (`feTurbulence`, opacidade de ~22%).

## Tipografia
- **Wordmark:** DM Sans Bold (700), tracking −3,5%
- **Tagline / UI:** DM Sans SemiBold (600)
- **Código:** qualquer monoespaçada (JetBrains Mono sugerida)

## Regras
- Espaço livre mínimo ao redor do símbolo: a largura de uma haste do "m".
- Não usar o símbolo sem a mordida, nem alterar o raio ou a posição do arco.
- Em tamanhos abaixo de 24 px, use a versão sem grão (a textura vira ruído).
- Para uso monocromático, o "m" fica sólido em Coral (sobre escuro) ou em Ink (sobre claro).
